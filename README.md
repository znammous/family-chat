# 💌 مجلس العائلة

مجلس يجمع أفراد العائلة في عالم فلفولة وأرنوبة: محادثة «بيت العائلة» للجميع، ورسائل خاصة بين كل فردين، وصور (من الألبوم أو كاميرا داخل التطبيق بإطار فلفولة وأرنوبة) ورسائل صوتية حتى دقيقة وإيموجي وملصقات، ولوحة «أخبار العائلة».

## كيف تنضم العائلة
- **ولي الأمر:** يدخل بحساب Google مرة واحدة، فتصبح العائلة مرتبطة بحسابه (نفس حساب أبطال الغابة وأبطال الإملاء).
- **الأبناء:** من جهاز ولي الأمر ← «العائلة» ← «أضف فرداً» ← يكتب الاسم فيظهر رمز QR. يمسحه جهاز الابن بالكاميرا أو من داخل المجلس، أو يكتب الرمز. الرمز صالح لعشر دقائق.
- **الأجهزة المرتبطة من قبل بأبطال الغابة أو أبطال الإملاء** تدخل المجلس تلقائياً بلا رمز جديد.
- **ولي أمر آخر** (مثل ماما): من «أضف فرداً» ← «👑 ولي أمر آخر» يظهر رمز لمرة واحدة، فيأخذ جهازها صلاحيات ولي الأمر كلها هنا وفي الألعاب (`families/{fid}/guardians/{معرّفها}`). ومن انضم قبل ذلك يمنحه ولي الأمر الصلاحيات بزر «👑 منح صلاحيات ولي الأمر» بجانب اسمه، ويسحبها منه بنفس المكان، والفصل يلغيها.
- ولي الأمر يرى كل المحادثات، ومنها محادثات الأبناء الخاصة (للاطلاع فقط)، ويستطيع حذف أي رسالة وفصل أي جهاز.
- من «العائلة» يضغط ولي الأمر 👀 بجانب أي فرد فيرى دردشاته الخاصة كلها كما يراها صاحبها (للاطلاع فقط).
- من «العائلة» ← «مجموعات العائلة» ينشئ ولي الأمر مجموعات للعائلة كلها باسم وأيقونة (مثل 🛒 أغراض البيت)، فتظهر في الدردشات تحت «بيت العائلة»، ويعيد تسميتها أو يحذفها مع رسائلها.
- في أي محادثة أو مجموعة: اضغط على الرسالة ← «↩️ رد» (أو اسحبها على الجوال) فيظهر الرد مع اقتباس منها، والضغط على الاقتباس ينقل إلى الرسالة الأصلية.
- من «الإعدادات» يوقف ولي الأمر الرسائل الخاصة بين الأفراد؛ يبقى «بيت العائلة» والأخبار، ويستطيع الأبناء مراسلة ولي الأمر وحده على الخاص.

## الخصوصية
- قواعد Firestore تسمح فقط لأجهزة العائلة بقراءة رسائلها، والمحادثة الخاصة لا يقرؤها إلا طرفاها وولي الأمر.
- لا يستطيع أحد إرسال رسالة باسم غيره، وكل فرد يحذف رسائله فقط.
- الصور تُصغَّر على الجهاز قبل الإرسال (أقل من 650 كيلوبايت)، والتسجيلات الصوتية حتى دقيقة، وكلاهما يُحفظ داخل الرسالة.

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `js/cloud.js` | الاتصال بـ Firebase: الدخول والانضمام بالرمز والأفراد والغرف والرسائل |
| `js/art.js` | رسم فلفولة وأرنوبة بمزاجاتهما، والملصقات والصور الشخصية |
| `js/app.js` | الشاشات: الترحيب، الانضمام، الملف، الدردشات، الغرفة، الأخبار، العائلة |
| `css/style.css` | عالم فلفولة (سماء وتلال خضراء) وعالم أرنوبة (وردي)، يختاره كل فرد لجهازه |
| `firestore.rules` | قواعد المشروع المشترك، متطابقة مع جدول الأبطال وأبطال الغابة وأبطال الإملاء |
| `sw.js` | حفظ ملفات المجلس للعمل بدون إنترنت، وعرض التنبيهات القادمة من الخادم |
| `functions/index.js` | دالة `chatPush`: يطلبها الجهاز بعد رفع رسالته فترسل تنبيه Web Push لمن تخصّه، فيصل والمجلس مغلق (مرة واحدة لكل رسالة، تُسجَّل في `chatPushSent`) |

## البيانات في Firestore
- `families/{fid}/chatUsers/{uid}`: اسم الفرد وصورته ودوره وآخر ظهور.
- `families/{fid}/chatRooms/{غرفة}/messages`: الغرف `family` و`news` و`dm_{uid}_{uid}` و`g_{معرّف}` للمجموعات.
- `families/{fid}/chatPush/{uid}`: عناوين تنبيهات أجهزة الفرد `subs = {مفتاح: {endpoint, keys, at}}`، يكتبها صاحبها فقط.
- `families/{fid}/chatConfig/settings`: إعدادات ولي الأمر (`dmOff` لإيقاف الرسائل الخاصة، و`groups` للمجموعات `{معرّف: {name, icon, at}}`)، تفرضها قواعد Firestore أيضاً: لا تُقرأ مجموعة ولا يُكتب فيها إلا ما دامت موجودة في `groups`.

## التنبيهات والمجلس مغلق
- من «العائلة» ← «الإعدادات» ← «🔔 تنبيه عند وصول رسالة» يحفظ الجهاز عنوان تنبيهاته، فترسل الدالة `chatPush` التنبيه عند كل رسالة: للعائلة كلها في «بيت العائلة» والأخبار والمجموعات، ولطرفي المحادثة الخاصة فقط (لا للمرسل).
- الآيفون: iOS 16.4 أو أحدث، وبعد تثبيت المجلس على الشاشة الرئيسية وتفعيل التنبيهات من داخله.
- مفتاح VAPID العام في `js/cloud.js` و`functions/index.js`، والخاص سرّ `VAPID_PRIVATE` في Secret Manager (للتجربة المحلية: `functions/.secret.local` ولا يُرفع).
- تحتاج الدالة خطة Blaze، ومنطقتها `me-central1` (الدوحة) لأن Cloud Functions لا تدعم `me-central2` منطقة قاعدة البيانات، ولا تسمح Google بمشغّلات Firestore هناك، لذلك يستدعيها المرسل بعد رفع رسالته.

## النشر
```bash
firebase deploy --only firestore:rules --project tablehero-d582b
firebase functions:secrets:set VAPID_PRIVATE --project tablehero-d582b   # مرة واحدة
firebase deploy --only functions --project tablehero-d582b
```
> أي تعديل في `firestore.rules` يُنسخ إلى المشاريع الأربعة قبل النشر.
> عند تعديل أي ملف، غيّر رقم `CACHE` في `sw.js` حتى يصل التحديث للأجهزة.

## التجربة على الجهاز
